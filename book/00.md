# はじめに

**初花**: ねえ、マリゴールド。「最適化」って言葉、最近よく聞くんだけど、なんだか難しそうで。数学の式がずらっと並んでるイメージなんだ。

**マリゴールド**: 本書 **サクサクPuLP** は、その式の壁を越えなくていい本だよ。Pythonの **PuLP** というライブラリを使って、「限られた条件の中で、いちばん良い答え」をコンピュータに探してもらう方法を、手を動かしながら覚えていく。

**初花**: 式を書かなくても、最適化ってできるの？

**マリゴールド**: 書くのは、ほとんど **表** だよ。「何を決めたいか」「何をよくしたいか」「何を守るか」を表に整理できれば、あとはそれをコードに写すだけ。式の記号は、付録Bにまとめておいた。

---

## 最適化で何ができるのか

**初花**: 具体的には、どんなことに使えるの？

**マリゴールド**: 「全部は選べない」「全部はできない」場面なら、たいてい使える。本書で扱う題材を並べてみよう。

| 場面 | 決めること | よくしたいこと | 章 |
|------|----------|-------------|----|
| 屋台の仕入れ | 何をいくつ仕入れるか | 利益 | 第1章 |
| お昼ごはん | 何をどれだけ食べるか | 費用（栄養は守る） | 第8章 |
| 工場の生産 | どの商品をどのラインで作るか | 利益 | 第9章 |
| 商品の配送 | どの倉庫からどの店へ運ぶか | 輸送費 | 第10章 |
| 仕事の割り当て | 誰がどの作業をするか | 人件費と公平さ | 第11章 |
| 予算の使い道 | どの施策を選ぶか | 効果 | 第13章 |
| 勤務シフト | 誰がいつ働くか | 人件費と希望 | 第15章 |
| 倉庫の場所 | どこに置くか | 固定費＋輸送費 | 第16章 |

**初花**: 屋台からお昼ごはん、工場まで。全部「組み合わせが多すぎて、手では選びきれない」問題なんだね。

**マリゴールド**: そう。人の直感では見落とす組み合わせを、ソルバーという計算プログラムが探して、しかも「これ以上良い答えはない」と確かめてくれる。

## 本書の進み方

**マリゴールド**: 本書は6つの部に分かれているよ。

```text
第1部（1〜3章）    最適化を体験しよう      … 屋台で「最適」を体験し、環境を作り、最初のモデルを書く
      ↓
第2部（4〜7章）    モデルの基本を身につける … 文章を表とコードに変え、答えを読み、間違いを直す
      ↓
第3部（8〜11章）   実践問題でモデル設計を学ぶ … 配合・生産・輸送・割り当て
      ↓
第4部（12〜16章）  整数計画法で組み合わせ問題を解く … 「選ぶ・選ばない」の0と1
      ↓
第5部（17〜20章）  実務で使えるプログラムにする … CSV・シナリオ比較・ソルバー選び・テスト
      ↓
第6部（21〜23章）  総合演習                 … 自分の事業と、自分の問題を最適化する
```

**初花**: 最後は「自分の問題」なんだ。

**マリゴールド**: 本書のゴールは、出来上がったモデルを動かせることではなく、**自分で問題を見つけて、モデルにできるようになること** だからね。第21章からは、初花が始める小さなお店の問題を、初花自身に解いてもらうよ。

**初花**: えっ、わたしがお店を？

**マリゴールド**: それは読んでのお楽しみ。

各章は、次の流れでできています。

| 部分 | 内容 |
|------|------|
| 導入の会話 | 初花が題材を持ち込み、章の流れをつかむ |
| N.1 〜 N.k | 考え方を、会話・表・短いコードで学ぶ |
| ハンズオン | 動くプログラムを書いて実行する |
| 振り返り | 章で分かったことを会話で整理する |
| 初花のメモ帳 | 要点3行 |
| マリゴールドの one more thing | 次に学ぶことへの一歩 |

## 二人の紹介

**初花**: そういえば、マリゴールドって、どうしてこんなに最適化に詳しいの？

**マリゴールド**: 実家の仕事で、物流や人の配置を考える場面が多かったんだ。倉庫がいくつもあって、どこから何を運ぶかで毎月の費用が大きく変わるから、子どもの頃から聞かされていたよ。

**初花**: 倉庫がいくつも……。うちには、梅の木と道場しかないよ。

**マリゴールド**: その梅の木が、本書の大事な題材になるんだ。英語では Marigold と書くけど、本書では「マリゴールド」と呼んでね。初花は試して、違和感を言葉にして、質問する役。私は用語や手順を整理して、次の一歩を示す役だよ。

| | 初花 | マリゴールド |
|---|------|------------|
| 本書での役 | 試す・違和感を言う・質問する（読者の代わり） | 用語・手順を整理し、次の一歩を示す |
| 得意なこと | 直感で「ここが変」と気づく | 気づいたことを、表とコードの言葉に直す |
| ときどき | 直感で答えて外す | 外れた理由を数字で見せる |

**初花**: わたし、直感で答えて外すんだ……。

**マリゴールド**: 外すのは大事なことなんだよ。直感がなぜ外れるのかを数字で確かめると、最適化を使う意味がよく分かるからね。第1章で、さっそく体験してもらうよ。

## 準備するもの

**初花**: パソコンには何が要るの？

**マリゴールド**: Python 3.12 以上と、PuLP 4.0.1。インストールの手順は第2章で一緒にやるから、今はPythonが入っていなくても大丈夫だよ。

| 必要なもの | 本書で使うバージョン | 使う章 |
|-----------|-----------------|------|
| Python | 3.12 以上 | 全章 |
| PuLP ＋ HiGHS | `pulp[highs]==4.0.1` | 第1章（読むだけ）、第2章から |
| pandas・openpyxl | 3.0.6・3.1.5 | 第17章から |
| pytest | 9.1.1 | 第20章 |
| CBC・GLPK・SCIP | 任意 | 第19章（ソルバーの比較） |

⚠️ 本書は **PuLP 4.0.1** で書いています。PuLP 4 は大きく作り直された版で、インターネット上に多い PuLP 3.x 以前の書き方とは、変数の作り方や結果の読み方が違います。古い記事のコードを動かしたいときは、付録Eを参照してください。

最適解が複数ある問題では、ソルバーやバージョンによって、目的関数の値が同じまま、変数の値だけが本文と違うことがあります。そのときも、目的関数の値が同じなら正しく解けています。
